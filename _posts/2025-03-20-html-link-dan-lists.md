## Penjelasan tentang link dan lists pada HTML.

Dalam Html, Link dan Lists adalah elemen yang sering digunakan untuk navigasi dan pengorganisasian konten. Berikut adalah Penjelasannya:
1. **Link dalam HTML**
Link dalam HTML digunakan untuk menghubungkan satu halaman web dengan halaman web lain. Link dapat dibuat dengan menggunakan tag `<a>` dan atribut `href`. Atribut `href` digunakan untuk menentukan URL tujuan link. Contoh:
    ```html
        <a href="https://www.example.com">Klik disini untuk mengunjungi website</a>
        <a href="halaman2.html">Pergi ke halaman 2</a>
        <a href="mailto:email@example.com">Kirim email</a>
    ```

2. **Lists dalam HTML**
Lists dalam HTML digunakan untuk mengorganisir konten menjadi daftar. Ada dua jenis lists dalam HTML:

    a. **Unordered Lists (UL)**
    Unordered lists menggunakan bullet points untuk menandai setiap item. Dibuat menggunakan tag `<ul>` dan `<li>`. Contoh:

    ```html
        <ul>
            <li>Apel</li>
            <li>Jeruk</li>
            <li>Mangga</li>
        </ul>
    ```
    b. **Ordered Lists (OL)**
    Ordered lists menggunakan angka atau huruf untuk menandai setiap item. Dibuat menggunakan tag `<ol>` dan `<li>`. Contoh:
    
    ```html
        <ol>
            <li>Belajar HTML</li>
            <li>Belajar CSS</li>
            <li>Belajar JavaScript</li>
        </ol>
    ```
